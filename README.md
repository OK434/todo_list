📅 Full Stack Todo Calendar App
A full-stack task management application that allows users to create, manage, and track tasks on a calendar.

Built with React, Node.js, Express, and MongoDB.

🚀 Live Demo
Frontend: https://todo-list-zi28.vercel.app

Backend API: https://todo-list-1-r6mx.onrender.com

✨ Features
User authentication (Signup / Login)
Personal task management
Calendar view for tasks
Mark tasks as completed
Delete tasks
Email reminders for daily tasks
Responsive UI
🛠 Tech Stack
Frontend

React

Backend
